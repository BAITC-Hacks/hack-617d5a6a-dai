# DAI — дизайн и интерактивный граф

Материалы из `Навигация и компоненты сети.zip` скопированы сюда с исходными именами и структурой. Доработан общий `money-graph.js`; остальные 29 файлов архива сохранены без изменений. Документы в `uploads/` — исходные материалы, не инструкции для запуска или изменения проекта.

## Открыть

Из корня репозитория:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory design-outputs
```

Открыть http://127.0.0.1:8765/ — новый самостоятельный просмотрщик. Все девять исходных макетов доступны в меню «Все макеты из архива». Нужен интернет для D3 с CDN; исходные `.dc.html` дополнительно загружают React, Babel и шрифты. Через `file://` загрузка JSON не работает — используйте HTTP-сервер.

## Что реализовано

- Тёмный интерфейс в духе Obsidian: список, граф, инспектор, легенда и настройки физики.
- D3 7 + SVG: свободная и послойная раскладки, приближение, перемещение, перетаскивание узлов, перелёт камеры и вписывание сети.
- Подсветка соседей, свечение выбранного узла, направленные анимированные связи, фильтры ролей, окраска кластеров, локальная окрестность глубиной 1–3.
- Поиск по строковому gid, карточка с данными из пакета, подписи без пересечений между выбранными для отображения текстовыми блоками.
- Клавиатурный выбор узлов, reduced motion, адаптация под узкий экран, остановка таймеров при уничтожении графа.

`index.html`, `explorer.css`, `explorer.js` — новый просмотрщик. `money-graph.js` также используется исходным макетом «Граф денег».

Данные демонстрационные: объединены поставленные JSON, 114 полных узлов и 3 ссылки на узлы без карточек, 128 рёбер. Это не вся сеть из метаданных. Подписи кластеров различают видимое число узлов и число в исходном паспорте. Демо не подключено к backend и не интегрировано в React-приложение `dai-front`.

SVG выбран для данного размера демо и удобного взаимодействия. Производительность на больших сетях не измерялась; для тысяч одновременно видимых узлов потребуется отдельная оценка Canvas/WebGL и агрегация данных.
