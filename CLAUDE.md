# DAI — «Граф денег» (HackAlem AI)

ТЗ: `task/HackAlem_AI_*.md`. Структура: `task/` — материалы организаторов (не менять), `pipeline/` — анализ графа → CSV, `dai-front/` — интерфейс, `docs/` — схема решения и гипотезы, `outputs/` — итоговые CSV.

Фронт живёт в `dai-front/`: npm/npx-команды запускать оттуда, пути в скилах (`src/...`, `openapi.json`) — относительно `dai-front/`.

## Git

- Перед каждым коммитом: `git pull --rebase --autostash`, решить конфликты, потом коммит. В `main` пушат несколько человек.
- Чужие коммиты не переписывать и не force-push'ить.

## README

Корневой `README.md` оценивает жюри: «README и воспроизводимость» — 25 из 100 баллов (ТЗ, таблица критериев). Держать его в порядке:

- Изменилась команда запуска, структура папок, выходные файлы, критерии/пороги ролей, стек → обновить README в том же коммите.
- К сдаче README должен содержать (ТЗ §10 и §9): запуск одной командой на чистой машине; критерии ролей и пороги; что на выходе; ограничения подхода; масштабирование до ~1 млн узлов; технологии; основной сценарий аналитика.
- Писать только то, что уже работает; планы помечать как план. Выводы о клиентах — гипотезы для проверки («признаки консолидации»), не утверждения.
- Детали частей — в их README (`dai-front/README.md`), в корне — короткое описание и ссылка.
